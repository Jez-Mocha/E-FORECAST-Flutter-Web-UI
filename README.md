# E-FORECAST Flutter Web UI

E-FORECAST is a Flutter-based web interface for a household electricity consumption and bill forecasting system.

## Technologies Used
- Flutter
- Dart
- Material Design

## Project Structure
- `lib/landing/` — Landing page sections and widgets
- `lib/models/` — Energy-related data models
- `lib/screens/` — Application screens
- `lib/theme/` — App colors and themes
- `lib/widgets/` — Reusable UI components
- `web/` — Web application files

## Getting Started

### Requirements
- Flutter SDK
- Dart SDK
- Visual Studio Code
- Google Chrome

### Run the Project

1. Open the project folder in Visual Studio Code.
2. Open the terminal in the project root.
3. Run:

```bash
flutter pub get
flutter run -d chrome
```

## Purpose
This repository contains the E-FORECAST user interface for development and academic project collaboration.
